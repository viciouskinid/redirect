# Android Chrome URL Shortcuts

## Purpose

This project provides a simple way to create Chrome shortcuts on Android that open a specific URL within a website, rather than redirecting to the website's main domain.

## The Problem

When creating shortcuts to websites on Android, some websites redirect users to their main domain or homepage instead of opening the specific page they intended.

This makes it difficult to create convenient home-screen shortcuts to individual pages or sections of a website.

## The Solution

This code provides a redirect mechanism that allows a shortcut to point to a specific URL on a domain.

Instead of simply opening:

`https://example.com/`

The shortcut can direct the user to:

`https://example.com/specific-page`

## Use Case

Useful for anyone wanting to create Android home-screen shortcuts that open particular pages within a website using Chrome, without having to navigate through the website manually each time.
